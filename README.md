# Astra AI Physics — Operational Interactive Platform

An interactive physics tutoring and simulation web application inspired by and reconstructed from `astra-ai.co/subjects/physics/#how-it-works`.

## Features
- **Socratic Step-by-Step Physics Solver (`#how-it-works`):**
  - Guided multi-step problems across Kinematics (Projectile Motion), Newtonian Dynamics (Inclined Plane with Friction), Conservation of Energy (Rollercoaster Loop), and DC Circuits (Series-Parallel Networks).
  - Real-time LaTeX equation rendering via **KaTeX**.
  - Built-in **Physics & Math Formula Keyboard**, custom problem parser, and worksheet image scanner.
- **Real-Time 60 FPS 2D Vector Physics Sandbox (`#physics-sim-canvas`):**
  - Live animated velocity/force vectors ($\vec{v}_x, \vec{v}_y, \vec{v}, mg\sin\theta, F_N, f_k$) and interactive parameter sliders.
- **Interactive Practice Studio (`#practise`):**
  - AB/CD & True/False Concept Checks, 3D-flip Flashcards, Spaced Repetition, AI Physics Tutor Chat, and `localStorage`-persisted XP & 7-Day Streak tracking.
